# Security policy reference: AD, DNS and Windows hardening settings

Generated from `windows\audit\Audit-SecurityPolicy.ps1 -Reference` - edit the script, not this file.
Run the script (panel `[P]`) to see the CURRENT value of each setting on a box.

**Safety:** `SAFE` = turn it on now, no effect on scored services in a normal pod. `CAUTION` = can break the thing named in "Breaks"; test first. `LEAVE` = do not change mid-competition.

**Which GPO?** Domain password/lockout policy only works in a GPO linked at the domain root (*Default Domain Policy*). DC-only settings go in *Default Domain Controllers Policy*. Member servers/workstations: a GPO on their OU, or `gpedit.msc`/`secpol.msc` on the box. Then `gpupdate /force`. "MS Security Guide" settings need `SecGuide.admx` from the Microsoft Security Compliance Toolkit; without it, use GPO Preferences > Registry with the value from "Fix".
